# Telegram AppStore Bot

Telegram-бот-«магазин приложений»: админ загружает приложения, пользователи просматривают, ищут, скачивают и добавляют в избранное.

## Возможности

- **Загрузка приложений** (только админ): название, описание, категория, эмодзи-иконка, версия, файл
- **Категории** — Игры, Инструменты, Обучение, Развлечения, Музыка, Продуктивность, Социальные, Прочее
- **Списки**: Новинки, Популярное (топ по скачиваниям), по категориям, с пагинацией
- **Поиск** по названию и описанию (`/search`)
- **Скачивание** файла из Telegram, счётчик скачиваний
- **Избранное** ⭐ — сохранение приложений у пользователя
- **Статистика** 📊 для админа (всего приложений, скачиваний, пользователей, топ-5)
- **Рассылка** 📢 всем пользователям (только админ)
- **Два языка**: русский / английский, переключается в меню
- **SQLite** вместо JSON — быстрее, надёжнее, с индексами
- Меню команд `/start`, `/menu`, `/search`

## Установка и запуск

1. Клонируйте репозиторий и установите зависимости:
   ```bash
   pip install -r requirements.txt
   ```
2. Создайте `.env` по образцу `.env.example`:
   ```env
   BOT_TOKEN=ваш_токен
   ADMIN_IDS=ваш_telegram_id
   DB_FILE=apps.db
   ```
3. Запустите:
   ```bash
   python bot.py
   ```

## Деплой на Render

В репозитории есть `render.yaml` — на Render выберите **New → Blueprint**, укажите репозиторий, задайте переменные `BOT_TOKEN` и `ADMIN_IDS`. Для предотвращения засыпания бесплатного инстанса добавлен GitHub Actions workflow (`.github/workflows/keep-alive.yml`), который пингует сервис каждые 5 минут.

## Мини-приложение «Панель админа»

Веб-панель для управления приложениями (просмотр, скрыть/показать, удалить, статистика). Размещается на GitHub Pages, API живёт на Render.

1. **Убедитесь, что `index.html` лежит в корне репозитория** (уже здесь).
2. **Включите GitHub Pages**: репозиторий → Settings → Pages → Source: `Deploy from a branch` → branch `master` → root `/` → Save.
3. Сайт станет доступен по адресу:  
   `https://mamadjonovali2012-blip.github.io/telegram-appstore-bot/`
4. В `index.html` при необходимости поменяйте `API_BASE` (сейчас `https://telegram-appstore-bot.onrender.com/`).
5. **Подключите кнопку в боте**: в @BotFather → `/mybots` → бот → Bot Settings → Menu Button → вставьте URL мини-приложения.

> ⚠️ Скачивание файлов и загрузка в веб-версии не реализованы — только управление (скрыть/удалить/статистика). Кнопка «Скачать» в боте продолжает работать штатно.

## Команды

| Команда | Доступ | Описание |
|---|---|---|
| `/start` | все | Главное меню |
| `/menu` | все | Меню |
| `/search <текст>` | все | Поиск |
| `/upload` | админ | Загрузить приложение |
| `/delete` | админ | Удалить приложение |
| `/edit` | админ | Редактировать приложение (название, описание, версия, имя файла, файл) |
| `/stats` | админ | Статистика |
| `/broadcast <текст>` | админ | Рассылка |
