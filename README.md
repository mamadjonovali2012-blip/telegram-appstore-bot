# Telegram AppStore Bot

Telegram-бот-«магазин приложений»: вы (админ) загружаете файлы приложений,
а любые другие пользователи могут просматривать каталог, искать и скачивать
их, но загружать ничего не могут.

## Возможности

- **Админ**: загрузка файла приложения с названием и описанием, удаление по ID.
- **Пользователи**: список всех приложений (постранично), карточка с кнопкой
  «Скачать», поиск по названию и описанию (`/search <текст>`).
- Хранение каталога — локальный JSON-файл `apps.json` (без БД).

## Установка и запуск

1. Установите Python 3.10+.
2. Создайте бота у [@BotFather](https://t.me/BotFather) и получите токен.
3. Скопируйте `.env.example` в `.env` и заполните:

   ```env
   BOT_TOKEN=ваш_токен
   ADMIN_IDS=ваш_telegram_id
   DB_FILE=apps.json
   ```

   `ADMIN_IDS` — через запятую, можно несколько. Свой ID узнайте у
   [@userinfobot](https://t.me/userinfobot).

4. Установите зависимости:

   ```bash
   pip install -r requirements.txt
   ```

5. Запустите:

   ```bash
   python bot.py
   ```

## Команды

| Команда | Доступ | Описание |
|---|---|---|
| `/start` | все | Приветствие и помощь |
| `/apps` | все | Список приложений |
| `/search <текст>` | все | Поиск по названию/описанию |
| `/upload` | админ | Загрузить приложение (название → описание → файл) |
| `/delete` | админ | Показать ID приложений |
| `/rm <id>` | админ | Удалить приложение по ID |

## Структура проекта

```
telegram-appstore-bot/
├── bot.py            # Точка входа, запуск polling
├── config.py         # Загрузка настроек из .env
├── storage.py        # Хранение каталога в JSON
├── handlers/
│   ├── admin.py      # Загрузка и удаление (только админ)
│   └── user.py       # Список, поиск, скачивание
├── requirements.txt
├── .env.example
└── .gitignore
```

## Примечания

- Файлы приложений хранятся на серверах Telegram (file_id), бот ничего не
  скачивает на диск.
- Если вы пересоздадите бота — старые `file_id` перестанут работать, каталог
  нужно будет заполнить заново.
- Запуск в production: используйте `systemd` (Linux) или
  `NSSM`/планировщик Windows (Windows), либо разверните на VPS.
